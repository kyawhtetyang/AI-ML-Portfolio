# Files Organizer

Files Organizer is a desktop workflow utility designed to reduce repetitive manual file sorting and cleanup.

Recruiter highlights:

- React and TypeScript frontend
- Python and FastAPI backend support
- Tauri desktop packaging
- rule-based file automation workflow

What it does:

- organizes files using defined sorting rules
- improves local workspace hygiene and speed
- turns repetitive manual actions into a lightweight desktop tool

What it proves:

- automation mindset
- cross-surface product building across web and desktop
- ability to package practical utilities for real daily workflows
