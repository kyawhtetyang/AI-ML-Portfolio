# Flask Cloud Storage

Flask Cloud Storage is a backend project for file upload, storage, retrieval, and management in a lightweight cloud-style workflow.

Recruiter highlights:

- Flask backend in Python
- Bootstrap-based frontend
- file upload and retrieval flow
- structured file listing and storage handling

What it does:

- accepts file uploads
- stores and lists uploaded files
- provides a simple file-management dashboard

What it proves:

- backend CRUD and file-handling skill
- practical application design beyond static pages
- ability to build useful workflow tools for everyday operations
