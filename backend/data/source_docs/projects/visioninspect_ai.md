# VisionInspect AI

VisionInspect AI is a recruiter-facing computer vision inspection platform concept focused on upload, detection, annotation, and reporting workflows.

Recruiter highlights:

- FastAPI backend
- PostgreSQL data layer
- React and TypeScript frontend
- Docker Compose runtime
- inspection-oriented AI product flow

What it does:

- supports inspection-style upload and detection workflow
- connects model output to annotation and reporting steps
- presents computer vision work in product-shaped form

What it proves:

- end-to-end product thinking for AI systems
- ability to design beyond isolated model demos
- interest in applied computer vision platform architecture

Current status:

- this project is positioned as a recruiter-facing demo direction and platform concept inside the portfolio
