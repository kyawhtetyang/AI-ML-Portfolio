# Article Analyzer SBERT

Article Analyzer SBERT is a semantic text analysis project that uses SBERT embeddings to compare article meaning and similarity.

Recruiter highlights:

- SBERT and transformer-based embeddings
- Flask backend in Python
- Docker packaging
- semantic similarity and ranking workflow

What it does:

- compares article meaning beyond keyword overlap
- supports semantic matching and clustering
- improves article analysis with embedding-based reasoning

What it proves:

- NLP representation learning awareness
- practical embeddings experience
- ability to package experimental NLP work into a usable application flow
