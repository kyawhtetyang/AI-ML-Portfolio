# RAG Knowledge Assistant

RAG Knowledge Assistant is a production-style retrieval-augmented generation project designed to prove end-to-end AI shipping discipline.

Recruiter highlights:

- FastAPI backend with a production-style API surface
- PostgreSQL and pgvector for retrieval storage
- React + Vite + TypeScript frontend for a polished public chat experience
- Gemini API answer generation with OpenAI-compatible adapter fallback
- Docker, Render, and Vercel deployment path
- PDF upload, ingestion, retrieval, citations, and evaluation endpoints
- public deployment at rag.kyawhtet.com, not just local notebook experimentation

What it proves:

- understanding of retrieval-augmented generation architecture
- backend and infrastructure ownership
- provider abstraction and safe fallback design
- ability to move from concept to public deployment
