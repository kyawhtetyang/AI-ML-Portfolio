# Flask POS Inventory

Flask POS Inventory is a retail workflow project focused on point-of-sale tracking and inventory visibility.

Recruiter highlights:

- Flask backend in Python
- SQLAlchemy and SQLite database flow
- dashboard-style retail operations support
- stock, transaction, and sales tracking

What it does:

- tracks inventory levels
- records retail transactions
- centralizes stock and sales visibility

What it proves:

- business workflow modeling
- backend application structure with persistent data
- ability to translate operational needs into software tools
