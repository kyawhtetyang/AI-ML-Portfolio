# Movie Recommender Hybrid

Movie Recommender Hybrid is a recommendation project that combines collaborative and content-based approaches for stronger suggestions.

Recruiter highlights:

- hybrid recommender logic
- Flask and FastAPI backend combination
- React frontend direction
- SQLite-backed application support

What it does:

- blends multiple recommendation signals
- improves movie suggestion relevance
- demonstrates ranking logic rather than only classification workflows

What it proves:

- recommender-system understanding
- ability to combine models and product behavior
- broader ML range beyond NLP alone
