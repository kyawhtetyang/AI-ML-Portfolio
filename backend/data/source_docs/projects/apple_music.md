# Apple Music

Apple Music is a polished frontend-heavy product demo inspired by Apple-style music interfaces and interaction quality.

Recruiter highlights:

- React and TypeScript frontend
- FastAPI backend direction
- Postgres and Cloudflare R2 data/storage path
- attention to UI hierarchy and interaction design

What it does:

- recreates a high-fidelity music app experience
- emphasizes navigation, layout, and interface polish
- demonstrates design-system consistency

What it proves:

- frontend implementation care
- ability to pair software engineering with UI quality
- broader product-building range beyond only backend or AI work
