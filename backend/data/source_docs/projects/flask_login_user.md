# Flask Login User

Flask Login User is a backend-focused authentication project built around user login, logout, and protected session flow.

Recruiter highlights:

- Flask backend in Python
- user authentication and account session handling
- protected routes and role-aware access patterns
- SQLite-backed application structure

What it does:

- provides secure login and logout flow
- manages authenticated user sessions
- demonstrates reusable auth foundations for Flask applications

What it proves:

- backend fundamentals
- authentication and session management experience
- ability to build reusable application modules instead of one-off pages
