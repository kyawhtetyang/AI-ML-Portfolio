# Image Classifier CNN

Image Classifier CNN is a computer vision project built around convolutional neural network classification.

Recruiter highlights:

- PyTorch CNN workflow
- OpenCV support
- Python inference pipeline
- practical image recognition baseline

What it does:

- classifies image categories
- demonstrates model training and inference flow
- serves as a practical computer vision baseline

What it proves:

- hands-on computer vision experience
- PyTorch familiarity
- ability to move from model training into runnable inference workflows
